# Git Terminal Quiz

ინტერაქტიული თეორიული ტესტი სტუდენტებისთვის, რომელიც ამოწმებს Git-ის ტერმინალის ბრძანებებისა და საბაზისო სამუშაო პროცესის ცოდნას.

## ფუნქციონალი

- 15 შეკითხვა, თითოეულზე 4 სავარაუდო პასუხით.
- სტუდენტის სახელისა და გვარის შეყვანა.
- თითო კითხვაზე ერთი პასუხის არჩევა.
- წინა და შემდეგ კითხვებზე გადასვლა და პასუხის შეცვლა.
- უპასუხო კითხვების გაფრთხილება ტესტის დასრულებამდე.
- ავტომატური შეფასება: მაქსიმუმ 15 ქულა და პროცენტული შედეგი.
- პასუხების მიმოხილვა განმარტებებით.
- შედეგის ეკრანი, რომელიც მოსახერხებელია სქრინშოტის გადასაღებად.
- რესპონსიული დიზაინი დესკტოპისა და მობილურისთვის.

## გამოყენება

პროექტს არ სჭირდება ინსტალაცია, პაკეტების ჩამოტვირთვა ან სერვერი.

1. ჩამოტვირთე ან დააკოპირე პროექტის ფაილები.
2. გახსენი `index.html` ბრაუზერში.
3. შეიყვანე სახელი და გვარი.
4. გაიარე ტესტი და დაასრულე.
5. ტესტის გავლის ბოლოს გადაიღე შედეგების გვერდის screenshot და გამოაგზავნე lms პლატფორმაზე

სურვილის შემთხვევაში პროექტი შეგიძლია გახსნა VS Code-ში და გაუშვა Live Server-ით.

## ფაილების სტრუქტურა

```text
git-terminal-quiz/
├── index.html
├── style.css
├── script.js
└── README.md
```

- `index.html` — გვერდის სტრუქტურა და სექციები.
- `style.css` — ვიზუალური გაფორმება და რესპონსიული განლაგება.
- `script.js` — შეკითხვები, პასუხების არჩევა, ნავიგაცია, შეფასება და შედეგების მიმოხილვა.

## ქულების დათვლა

- თითოეული სწორი პასუხი: 1 ქულა.
- მაქსიმალური შედეგი: 15 ქულა.
- პროცენტი გამოითვლება ფორმულით: `(სწორი პასუხების რაოდენობა / 15) × 100`.
- არასწორი და უპასუხო შეკითხვები ქულას არ იძლევა.
